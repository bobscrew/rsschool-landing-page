# Interactive Security

Агрегатор охранного оборудования: панели, извещатели и аксессуары
с проверкой совместимости и фильтрами по параметрам.

## Live Demo
Ссылка будет добавлена после деплоя.

## Технологии
- HTML5 (semantic markup)
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (ES modules)

## Структура проекта
- `index.html` — главная страница
- `catalog.html` — страница каталога
- `css/` — стили
- `js/` — скрипты
- `resources/` — изображения и иконки
